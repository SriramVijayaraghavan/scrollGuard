# iPhone setup (all free)
1. Install **Userscripts** (App Store, free). Settings → Safari → Extensions → turn on Userscripts, allow instagram.com and tiktok.com.
2. Open the Userscripts app, choose a folder (e.g. in iCloud Drive), and put `scrollguard.user.js` in it.
3. Host the `scrollguard` folder (GitHub Pages is free), open it in Safari → Share → Add to Home Screen.
4. Always open Instagram/TikTok from ScrollGuard so the blocker gets your latest limits and unlocks.
5. Delete the native Instagram/TikTok apps (they can't be blocked) and use the sites in Safari.
## Optional gate: Shortcuts → Automation → App → Instagram "Is Opened" → Open URL (your ScrollGuard link). Turn off "Ask Before Running".

## Using the real TikTok (or Instagram/YouTube) app: the gate
1. In ScrollGuard → Limits → "App gate", tap **Copy link** next to the app.
2. Shortcuts app → Automation → + → Personal Automation → **App** → choose the app → **Is Opened** → Next.
3. Add action **Open URLs**, paste the link, Next, then turn **off "Ask Before Running"** and Done.
4. Opening the app now jumps to ScrollGuard's lock screen first. If the app is unlocked, tap "Open …" to continue.
Note: this is a speed bump, not a hard block. For a hard limit also use iOS Screen Time → App Limits and give the passcode to a friend.
